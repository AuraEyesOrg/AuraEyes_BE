## 3.1.4 Non-Screen Functions

| # | Feature | System Function | Description |
|---|---|---|---|
| 1 | System Readiness | Database Initialization | Initializes the database at startup, applying migrations, schema updates, and essential seed data. |

| 3 | Clinical Documentation | PDF Report Generation | Automatically compiles clinical data into a standard 23/BV-01 PDF format for printing. |
| 4 | Communication | Automated Notifications | Sends transactional emails and SMS for appointment reminders and diagnostic availability. |

| 6 | Integration | API Gateway Service | Provides standardized endpoints for frontend communication and potential third-party lab integrations. |
| 7 | Data Sync | Internal Event Bus | Synchronizes state between modules (e.g., notifying Cashier when a Doctor finalizes a diagnosis). |
| 8 | Maintenance | Background Job Monitoring | Monitors the health and status of asynchronous tasks like AI heat-mapping and data backups. |
